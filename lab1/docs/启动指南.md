# 实验一 · 启动指南

> 把这个 Compose 项目从「代码骨架」到「跑起来看到 3 张任务卡片」需要做的事。

> 注意:目前缺少 `gradle-wrapper.jar` 二进制文件,Android Studio 第一次打开会自动补全,需要联网。

## 1. 打开项目

1. 启动 Android Studio(D:\Android\Android Studio\bin\studio64.exe)
2. **File → Open...** → 选择 `d:\rain_android\lab1` 目录
3. 弹出"Trust Project?"选 **Trust**

## 2. 等待 Gradle Sync

打开后 Android Studio 会自动尝试同步 Gradle。第一次比较慢,需要下载:
- Gradle 8.10.2 本体(几十 MB)
- AGP 8.7.2 + Kotlin 2.0.21 + Compose BOM 2024.10.01 等依赖

**如果失败**:
- File → Settings → Gradle → 检查 Gradle JDK 是否为 17
- 网络:Android Studio 默认用代理,Settings → Appearance & Behavior → System Settings → HTTP Proxy → "No proxy" 试试

## 3. 配置 SDK

如果提示 SDK 路径不对,设置:
- File → Project Structure → SDK Location → Android SDK Location: `D:\Android\Sdk`

或在项目根目录创建 `local.properties`(已加入 .gitignore,不会提交):

```properties
sdk.dir=D:\\Android\\Sdk
```

## 4. 创建模拟器

1. Tools → Device Manager → Create Device
2. 选 Pixel 7(或 Pixel 6)
3. System Image 选 **API 37**(与 compileSdk 一致),第一次会下载约 1GB
4. 启动模拟器,等到开机完成

或用真机:手机开启「开发者选项 → USB 调试」,USB 连接电脑。

## 5. 运行 Hello Compose

1. 顶部工具栏选 `app` 配置 + 选刚才创建的模拟器/真机
2. 点 ▶ Run(或 Shift+F10)
3. 等几十秒,模拟器上看到「实验一 · Compose 任务卡片」标题 + 3 张任务卡片

预期看到(自上而下):
| 标题 | 负责人 | 状态图标 | 标题颜色 |
|---|---|---|---|
| 完成实验报告 | 张三 | ⊙ 进行中 | 红色(高优先级) |
| 提交代码到 Git | 李四 | ✓ 已完成 | 默认色 |
| 复习 Kotlin 空安全 | 未分配 | ⊙ 进行中 | 灰色(低优先级) |

第 3 条验证了 **owner=null → Elvis 显示"未分配"** 的空安全分支。

## 6. 看 Preview(不需要跑模拟器)

打开 `ui/TaskCard.kt`,右上角点 **Split** 或 **Design** 视图,可看到 3 个 Preview:
- PreviewTaskCardInProgress — 进行中任务
- PreviewTaskCardCompleted — 已完成任务
- PreviewTaskCardUnassigned — 未分配负责人

打开 `MainActivity.kt` 同样能看到 `PreviewAppScreen` 整页预览。

## 7. 故障排查表

| 报错 | 原因 | 解决 |
|---|---|---|
| `Could not find gradle-wrapper.jar` | 用 Write 生成项目时跳过了二进制 | Android Studio 第一次 sync 时自动补;或手动执行 `gradle wrapper` |
| `Failed to resolve: androidx.compose.xxx` | 网络问题 / 仓库地址问题 | 项目根 build.gradle.kts 已配置 google()/mavenCentral(),试 File → Sync |
| `compileSdk 37 not found` | SDK 没装 API 37 | SDK Manager 装 Android SDK Platform 37 |
| `JDK 17 not found` | Android Studio 自带 JBR 17,但 Gradle JDK 设置错 | File → Settings → Gradle → Gradle JDK 选 "Embedded JBR 17" 或 "JAVA_HOME 17" |
| Compose Preview 不显示 | 需要等编译完成 | Build → Make Project,等待成功后看 |
| Preview 显示 "Compose UI not available" | 项目还没成功 sync | 先解决 sync 问题 |

## 8. Git 提交(实验指导书要求保留 3 个有意义节点)

实验指导书 B 部分要求:**至少保留 3 个有意义的 Git 提交节点:起始、主要功能、最终修复**。禁止只在实验结束时一次性提交全部文件。

按这个节奏提交(我已为你做了"起始"提交,你接下来做"主要功能"和"最终修复"):

```bash
# 起始提交(已做):项目骨架
git log --oneline    # 看到 "init: lab1 compose skeleton"

# 主要功能:你完成验收点后提交
git add app/src/main/java/
git commit -m "feat: implement TaskCard and MainActivity with sample data"

# 最终修复:解决一个真实故障后提交
# 例如修复 import 顺序、Preview 不显示、Elvis 链写错等
git add .
git commit -m "fix: <你的真实故障描述>"
```

## 9. 验收点自检(实验指导书 E 部分)

- [ ] 项目可编译运行,无红色异常 → Run 看能不能起来
- [ ] TaskCard 能显示两种状态 → 看图标 ⊙/✓ 切换
- [ ] 代码中无无理由 `!!` → 在 Android Studio 用 Code → Analyze Code → Inspection
- [ ] 至少一个 Composable 可独立 Preview → 看 `PreviewTaskCardInProgress` 等
